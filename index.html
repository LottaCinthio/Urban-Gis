Content Öxnehaga Descriptions

General Information
The right-side panel is the main control interface of the map application. It allows users to manage map layers, choose the basemap, and explore different thematic datasets such as emergency services, infrastructure, and buildings. Users can toggle layers on or off to visualize specific information, analyze spatial relationships and interact with urban data in the Öxnehaga area.
Emergency Services & Safety
This dataset was created in ArcGIS Pro by mapping locations of emergency facilities such as hospitals, fire stations, and police stations. Incident points and response routes were generated for simulation purposes and exported as GeoJSON for use in the web map. Respone routes give information about service, priority and time when pressed on. The incidents have been simulated.
Accessibility & Amenities
This dataset includes public amenities and accessibility-related features such as healthcare and schools available in the area. The data was collected from open spatial datasets and GIS sources, processed in ArcGIS Pro, and published as web layers to visualize walking accessibility within the neighborhood.
Interactive Analysis
Users can interact with the map to generate routes and compare travel metrics—including distance, duration, and speed—across three modes of transport. These routes are derived from an ArcGIS Pro GeoJSON export; however, the analysis is specifically constrained to the driving road network.
BIM

3D buildings on the map have been exported as geojson files from ArcGis Pro with their height coded using Esris OpenStreetMap 3D Buildings-service.

The Project Building with building id 8052 allows to view a 3D model that were generated from IFC (Industry Foundation Classes) file to a HTML -based 3D viewer. The 3D viewer allows users to interact with surrounding buildings and roads exported from ArcGis Pro as geojson files.
